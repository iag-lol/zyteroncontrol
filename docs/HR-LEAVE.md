# Vacaciones, permisos y licencias

Los saldos se derivan de `leave_ledger` (`ACCRUAL`, `USED`, `ADJUSTMENT`, `CARRYOVER`, `EXPIRATION`). Todo ajuste incluye actor y motivo. Se detectan superposiciones y un override requiere justificación.

Las licencias médicas tienen RLS independiente. Jefaturas operativas consumen solamente el estado de ausencia; documentos o antecedentes médicos quedan reservados a RR.HH. autorizado y al propio trabajador cuando corresponda.
