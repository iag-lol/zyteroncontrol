# Privacy Impact Assessment

Triggers configurables: datos altamente sensibles, tratamiento masivo, IA, biometría, monitoreo sistemático, nueva integración o fuente. Una DPIA registra propósito, alcance, necesidad, riesgo, impacto, controles, riesgo residual, owner, reviewer y aprobación.

La aprobación técnica no reemplaza revisión legal. Un feature marcado de alto riesgo no debe superar el Security Gate mientras su DPIA requerida permanezca pendiente.
