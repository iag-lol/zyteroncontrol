# Data Protection

El inventario conecta activo, categoría, clasificación, propósito, roles de acceso, ubicación, cifrado y retención. Las actividades de tratamiento documentan titulares, origen, destinatarios, transferencias, medidas y metadata de base jurídica.

Las solicitudes de titulares requieren verificación de identidad, discovery transversal, revisión y decisión. Legal hold prevalece sobre eliminación automática. El cumplimiento de Ley 19.628/21.719 requiere validación jurídica/DPO.
