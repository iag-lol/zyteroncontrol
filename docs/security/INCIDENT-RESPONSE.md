# Incident Response

Estados: DETECTED → TRIAGE → CONFIRMED → CONTAINING → INVESTIGATING → ERADICATING → RECOVERING → MONITORING → RESOLVED → POSTMORTEM → CLOSED.

Cada transición requiere motivo y agrega un evento append-only. Evidencia sensible se guarda en Documents como RESTRICTED/CRITICAL. Una posible brecha abre evaluación de privacidad; la plataforma no emite conclusiones legales automáticas.
