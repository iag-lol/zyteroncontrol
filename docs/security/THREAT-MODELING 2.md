# Threat Modeling

Prioridad: Auth, Finance/Payments, Documents, Vault, HR, Portal Cliente, Support público y Monitoring SSRF. Cada modelo registra activos, trust boundaries, amenazas, controles y riesgo residual.

STRIDE puede orientar, sin limitar el análisis. Features con nueva integración, datos sensibles, uploads, auth, pagos, IA o endpoint público requieren Security Review.
