# Data Loss Prevention

El control inicial registra exportaciones: actor, módulo, filtros seguros, volumen, clasificación, motivo, cliente y request ID. Volumen anómalo genera evento; no bloquea automáticamente todo uso legítimo.

Nunca se guarda el dataset completo en el evento. Screenshots no pueden impedirse de forma fiable. Watermarking futuro no modifica originales firmados. Datos enviados a IA deben minimizarse y redactarse.
