# Onboarding

Las plantillas se configuran por cargo o área. Cada tarea pertenece a HR, Security, Manager, IT, Finance o Employee. El flujo emite eventos para creación de cuenta y acceso, pero RR.HH. no crea credenciales.

La activación exige el 100% de tareas del flujo. Documentos, activos y accesos permanecen en sus fuentes centrales.
